Built to fill the gaps

ProxUI isn't a replacement for the Proxmox web UI — it's a lightweight addition that surfaces the information you care about, more clearly.

Guest Agent insight

Deep QEMU Guest Agent integration surfaces real per-filesystem disk usage instead of the raw block-device numbers Proxmox shows by default.

LXC passthrough, no SSH required

Configure GPU/iGPU passthrough, bind mounts, feature flags (nesting, keyctl, fuse) and unprivileged idmaps entirely through the API — no more hand-editing /etc/pve/lxc/*.conf over SSH.

Reusable container profiles

One-click profiles for common workloads (Jellyfin QuickSync, Immich, Docker-in-LXC, Tailscale) with a diff preview before anything is applied.

Multi-cluster command center

Connect and switch between multiple Proxmox clusters or standalone nodes from a single interface, with saved connections and live health status.

Mobile-ready console

Full noVNC console access to VMs and containers with a built-in on-screen virtual keyboard, designed to actually work on a phone or tablet.

Full cloud-init support

One-click VM templates from popular cloud images (Ubuntu, Debian, Rocky, Alma, Fedora, FreeBSD, OpenBSD, NetBSD), plus native cloud-init editing — users, networks, SSH keys — with custom snippet support for anything the native fields don't cover.

Node health at a glance

Per-node view of storage, local disks with SMART health, and ZFS pool status — the hardware picture Proxmox's summary tab doesn't give you.

Background job tracking

Long-running operations (clones, template builds) run as background jobs with real-time step-by-step progress instead of a spinning page.

Built for every screen

A responsive layout with light/dark mode that's equally at home on a workstation or a phone during an on-call fire drill.

Multi-cluster

All your clusters, one window

Stop juggling browser tabs and bookmarks. Register every cluster once, then jump between them instantly from the switcher — each with its own nodes, guests and health at a glance.

Get started

Self-host in one command

No account, no cloud, no telemetry. Run ProxUI on any machine or container, then point it at your Proxmox cluster.

# Run with Docker
docker run -d \
  -p 8080:8080 \
  -v proxui-data:/app/data \
  ghcr.io/greenlogles/proxui:latest
# Docker Compose
wget -O docker-compose.yml \
  https://raw.githubusercontent.com/greenlogles/ProxUI/main/docker-compose.yml
docker compose up -d
# From source (Python 3)
git clone https://github.com/greenlogles/ProxUI.git
cd ProxUI
pip install -r requirements.txt
python app.py
Then open http://localhost:8080 and connect to your Proxmox cluster.
